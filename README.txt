July 2026 metric montage experiment

The July 2026 experiment was the first technical test on the database. It was discontinued because PySceneDetect's default pipeline produced highly inaccurate shot-boundary detections on black-and-white films.

The October 2026 pilot superseded and extended the July experiment. In a comparison with human annotations covering both colour and black-and-white films, the pilot matched 43 of 45 annotated shot boundaries within an 80 ms tolerance.

This archive preserves the experiment notebooks, source code, metadata and outputs. The TransNetV2 notebooks refer to a separate upstream dependency at https://github.com/soCzech/TransNetV2.
